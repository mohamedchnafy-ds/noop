## PR A — ce qui est codé (fusionné)
- **Pause dans le moteur** (`LiftSessionEngine`) : `pausedAt`, `pausedTotalSec`, `pauseSession(now:)`, `resumeSession(now:)`, `clockNow(_:)`, `stageSeconds(now:)`, `sessionSeconds(now:)`, `activeSeconds(until:)` (via `ActiveWorkoutClock.activeElapsed`). À la reprise, le début de l'étape et la fin d'un repos qui avait encore du temps avancent de la durée de la pause ; un repos déjà fini reste fini. Pas une étape d'Undo.
- En pause : pas de vibration d'avertissement, pas de tour suivant automatique (`isNextRoundDue` faux, minuteurs annulés). **Double-tap du bracelet sans effet** (pas de vibration, une ligne de journal). Un bouton de l'app **reprend d'abord**, puis agit. Terminer en pause termine la pause d'abord.
- **Durée enregistrée sans les pauses** : `WorkoutRow.durationS` = `activeSeconds`. Un seul calcul, **`TrainingDays.liftSessionSeconds`** (durée de la ligne d'entraînement, sinon fin − début), lu par le calendrier (`TrainingLiftDone.activeSeconds`), la Synthèse (« faite · n min », « ≈ n min »), la durée habituelle d'un programme, la fiche d'une séance, le message au Coach après la séance. Aucune migration.
- Persistance : `pausedAt` / `pausedTotalSec` optionnels dans `LiftSessionPersistence`.
- **Dans l'app** : pause/lecture à côté d'Annuler (feuille de séance ; en pause le gros bouton devient « Reprendre ») ; écrans superset guidés : bouton ▶/⏸ dans l'en-tête, « EN PAUSE », « Reprendre » seule action ; barre réduite grise avec ▶.
- **Bannière + Dynamic Island** : `LiftSessionController.bannerControls` ; `LiftBannerActionIntent` (`LiveActivityIntent`, `StrandiOSShared/LiftBannerIntent.swift`, compilé dans l'app ET l'extension) → `LiftBannerActionRelay.handler` (enregistré dans `StrandiOSApp.init` après `resumeSaved()`) → `StrandiOSApp.pushLiftBanner` → `LiftLiveActivityController.flushUpdate`.
