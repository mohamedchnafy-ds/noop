Règle : **un seul chantier de code à la fois**. Pendant la validation (5), plusieurs petites PR de correction peuvent être ouvertes en même temps, chacune depuis `main`, une préoccupation chacune. Les maquettes peuvent avancer en parallèle : elles ne touchent pas au code.
